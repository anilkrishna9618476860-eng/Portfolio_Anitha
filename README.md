# Bachu Anitha – Personal Portfolio

Welcome to my personal portfolio! This repository contains the source code for my portfolio website, where I showcase my academic journey, technical skills, projects, achievements, certifications, and experiences.

## 🌐 About the Website

This is a single-page, responsive portfolio website designed with a modern dark-themed interface. It provides an overview of my background, technical interests, work, and accomplishments.

## ✨ Sections

- **Introduction** – A brief introduction and profile.
- **Education** – My academic background.
- **Experience** – My internships, responsibilities, and activities.
- **Projects** – A collection of my technical projects.
- **Skills** – Programming languages, technologies, and tools.
- **Achievements** – Hackathons, recognitions, and extracurricular accomplishments.
- **Certifications** – Courses and certifications I have completed.
- **Contact** – Links to connect with me.

## 🛠️ Technologies Used

- HTML5
- CSS3
- Google Fonts

## 🎨 Design Highlights

- Modern dark-themed interface
- Responsive layout
- Smooth scrolling navigation
- Interactive hover effects
- Clean and organized sections
- Blue, violet, and teal accent colors
